Admin password change

UI: Admin Settings -> Change admin password.
Fields: current password, new password, confirmation.
API: POST /api/auth/change-password with Bearer authentication and ADMIN role.
Body: { currentPassword, newPassword }. Identity comes from the authenticated session.
New password: at least 8 characters, maximum 72 UTF-8 bytes (bcrypt limit).
Incorrect current password, unchanged password or invalid body: 400.
Missing/invalid session: 401. CUSTOMER: 403. Concurrent account change: 409.
Success: { success: true, message: ... }; current session stays active, other sessions
belonging to this admin are revoked. Other users' sessions remain unchanged.
Hash update and revocations use one database transaction with compare-and-swap on
original hash. No raw password/hash is returned or logged.
